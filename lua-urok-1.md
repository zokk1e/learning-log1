## 1. Что вообще делает программа

Программа — это список команд, которые компьютер выполняет по порядку, сверху вниз. Всё. Пока никакой магии.

Первая команда, которая тебе нужна:

```lua
print("Привет")
```

`print` — «покажи на экране». То, что в скобках, появится внизу, в выводе.

Попробуй прямо сейчас. Потом поменяй текст на свой и запусти снова.

## 2. Комментарии

Строка, которая начинается с `--`, — это записка для себя. Компьютер её не читает.

```lua
-- это комментарий, программа его игнорирует
print("А это выполнится")  -- а это комментарий в конце строки
```

Комментарии нужны, чтобы через месяц понять, что ты имел в виду. Пиши их.

## 3. Переменные — коробки с именами

Переменная — это коробка. У коробки есть имя, внутри лежит значение.

```lua
local name = "Егор"
local hp = 700
```

Читается так: «создай коробку `name` и положи туда текст `Егор`». Знак `=` здесь не «равно», а «положи в коробку».

Достать значение — просто написать имя:

```lua
local name = "Егор"
print(name)
```

### `local` — что это

`local` значит «коробка видна только в этом куске кода». Пока не понимаешь зачем — **пиши `local` всегда**. Без него переменная становится глобальной, и это источник странных ошибок.

```lua
local x = 10   -- локальная, хорошая
y = 20         -- глобальная, так лучше не делать
```

## 4. Типы: что может лежать в коробке

В Lua всего несколько типов, и на старте нужны четыре:

| Тип | Что это | Пример |
|---|---|---|
| `number` | число | `700`, `3.14`, `-5` |
| `string` | текст в кавычках | `"Егор"`, `"привет"` |
| `boolean` | да или нет | `true`, `false` |
| `nil` | пусто, ничего | `nil` |

Проверить, что лежит в коробке, можно функцией `type()`:

```lua
print(type(700))        -- number
print(type("Егор"))     -- string
print(type(true))       -- boolean
print(type(nil))        -- nil
```

`type` возвращает текст, поэтому его можно сразу печатать.

## 5. Строки и склейка

Строка — это текст в кавычках. Кавычки могут быть двойные `"..."` или одинарные `'...'`, разницы нет.

Склеиваются строки **двумя точками**:

```lua
local name = "Егор"
print("Привет, " .. name .. "!")
```

Выведет: `Привет, Егор!`

> **Важно:** именно `..`, две точки. Одна точка — это ошибка. Плюс `+` для строк не работает, он только для чисел.

Число тоже можно приклеить к строке — Lua сам превратит его в текст:

```lua
local hp = 700
print("HP: " .. hp)   -- HP: 700
```

### `string.format` — аккуратная подстановка

Когда склеивать много кусков неудобно, используют `string.format`. `%d` — место для числа, `%s` — место для строки.

```lua
local name = "Егор"
local hp = 700
print(string.format("Игрок %s, HP: %d", name, hp))
```

Выведет: `Игрок Егор, HP: 700`

## 6. Числа и арифметика

```lua
print(2 + 3)    -- 5
print(10 - 4)   -- 6
print(3 * 4)    -- 12
print(10 / 4)   -- 2.5
print(10 % 3)   -- 1  (остаток от деления)
```

`%` — остаток от деления. Полезная штука: `10 % 2 == 0` значит «делится на 2 без остатка».

Переменные можно менять:

```lua
local hp = 700
hp = hp - 200      -- теперь в коробке 500
print(hp)
```

`hp = hp - 200` читается «возьми то, что в hp, вычти 200 и положи обратно». Это не уравнение, а команда.

---

## 7. Сравнения и boolean

Сравнения возвращают `true` или `false`:

```lua
print(700 > 500)    -- true
print(700 < 500)    -- false
print(700 == 700)   -- true
print(700 ~= 500)   -- true (не равно)
```

> **Ловушка №1:** `=` кладёт значение, `==` сравнивает. `if hp = 500` — ошибка, нужно `if hp == 500`.

> **Ловушка №2:** `~=` — это «не равно». Не `!=`, как в других языках.
